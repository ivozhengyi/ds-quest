# 公开版与验证范围

公开版从本地学习项目独立导出，未修改原学习目录与用户存档。

保留 55 个初学教程、37 个复习专题、120/371 道两轮题目、25 个演示及判分/存档功能。第三方 PPT、扫描 PDF、扫描页图和提取全文不公开；`sources.js` 只有原页索引及空文本，便于保留引用编号与检查覆盖，不冒充可访问的原件。

开发时资料含一份有年份正式卷、一份未标年份样卷，以及重复/手写整理页；未把扫描页数当独立卷数。公开训练沿用有限样本的任务结构，不能推断考试概率。

## 检查

六组检查覆盖题库、教学、课程范围、独立枚举图算法、数学排版及学习状态。公开版额外核对移除原件后的来源按钮和引用提示。两张 README 截图来自本地完整版的教学与练习界面；公开版这些内容与布局保持一致，但来源档案入口改为公开说明。

## 内容维护

`content.js` 与 `learning-guides.js` 提供初学内容；`review-lessons.js` 为复习专题；`learn-bank.js`、`review-bank.js` 是两套题库。`training-engine.js` 为判分与组卷；`curriculum.js` 和 `exam-meta.js` 为课程覆盖与训练安排。

生成脚本位于 `维护/`。修改生成内容时，先改对应脚本/数据来源并检查生成差异，避免下次重建覆盖修正。重建可能重新带出私人版本的来源 UI 或文案，应按本说明检查后再发布。
